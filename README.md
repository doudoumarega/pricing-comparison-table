# Pricing Comparison Table

An accessible, HTML-only pricing comparison table built for the [roadmap.sh Pricing Comparison Table project](https://roadmap.sh/projects/pricing-comparison-table).

## Project Overview

This exercise focuses on semantic HTML and accessible tables rather than CSS styling. The page compares three subscription plans: Free, Pro, and Business.

## Features

- Semantic HTML using `header`, `main`, and `footer`.
- Accessible table with `caption`, `thead`, and `tbody`.
- Column headers using `scope="col"`.
- Row headers using `scope="row"`.
- A merged cell using `colspan="4"`.
- Basic HTML metadata.
- No CSS or JavaScript required.

## How to Run Locally

1. Clone or download this repository.
2. Open `pricing-comparison-table.html` in any modern browser.
3. View the pricing comparison table.

No installation or server is required.

## Learning Objectives

- Structure tabular data with semantic HTML.
- Create accessible row and column headers.
- Understand the difference between `th` and `td`.
- Use `colspan` to merge cells.
- Build accessible HTML without CSS.
